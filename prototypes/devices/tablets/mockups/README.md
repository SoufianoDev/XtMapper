# Android Tablet Mockups

Keep Android tablet-frame PNG or WebP assets in this directory.

Do not add iPad or other iOS mockups.

Before copying an asset into this public repository, verify that the terms on that exact device page permit local hosting and embedding in a public project. The Mobile FIRST collection page and individual mockup pages may use different wording.

After approval, add the asset path and measured screen rectangle to the matching device entry in ../index.mjs. Measure the screen rectangle from the actual image. Do not estimate its insets.
